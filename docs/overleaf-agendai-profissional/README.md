# Relatório Overleaf — Agend.AI Profissional

Projeto LaTeX preparado para importação direta no Overleaf.

## Como usar

1. Importe o arquivo ZIP no Overleaf ou envie os arquivos mantendo a pasta `assets/`.
2. Defina `main.tex` como documento principal, caso o Overleaf não o detecte automaticamente.
3. No início de `main.tex`, substitua os seguintes campos:
   - `NOME DA INSTITUIÇÃO`;
   - `NOME DO CURSO`;
   - `NOME DO PROFESSOR`;
   - `NOME DO ALUNO`;
   - `CIDADE`.
4. Compile com pdfLaTeX.

O documento utiliza a classe `abntex2`, margens de 3 cm na parte superior e esquerda, 2 cm na parte inferior e direita, fonte de 12 pontos, espaçamento 1,5 e referências no sistema autor-data.
