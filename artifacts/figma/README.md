# Agend.AI Profissional — telas do MVP mobile

Arquivo para importação no Figma:

- `AgendAI-Profissional-MVP-Telas.svg`: board único com 15 telas mobile e seis padrões de estado.
- `AgendAI-Profissional-MVP-Telas-preview.png`: prévia rasterizada para conferência rápida.

## Como importar

1. Abra a página `App` do arquivo `Agend.AI` no Figma.
2. Arraste `AgendAI-Profissional-MVP-Telas.svg` para a página ou use **File → Place image**.
3. Mantenha a proporção original durante a inserção.
4. Se necessário, use **Ungroup** para acessar os grupos internos de cada tela.
5. Converta cada grupo `screen-*` em frame para continuar a prototipação.

O board usa frames de referência de 390 × 844 px, margem lateral mínima de 20 px e alvos de toque de pelo menos 44 × 44 px. As famílias tipográficas indicadas são Hanken Grotesk e Inter.

O SVG foi adotado como fallback porque o limite de chamadas do Figma MCP no plano Starter permaneceu ativo em 28/08/2026.
